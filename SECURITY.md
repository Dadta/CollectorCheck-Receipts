# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or discussions. Use GitHub's private vulnerability reporting for this repository:

https://github.com/Dadta/CollectorCheck-Receipts/security/advisories/new

If private reporting is unavailable, contact the repository maintainers privately through GitHub and include steps to reproduce, affected versions, and potential impact. Do not include real receipts, credentials, access tokens, or other personal data in a report.

We will acknowledge reports as soon as practical and coordinate a fix and disclosure with the reporter.# Security Policy
