# PhoneBurp — Game Design Document (GDD)

## 1. High Concept
PhoneBurp is a symbolic gig‑economy continuity simulator. Players operate Gig Machines to earn game points, buy continuity items, collect receipts, and stabilize their symbolic life. Half the enjoyment comes from gameplay, half from customization.

## 2. Core Loop
WORK → EARN POINTS → BUY CONTINUITY → GET RECEIPTS → SCAN → SURVIVE → CUSTOMIZE EVERYTHING

## 3. Gig Machines
### Transport Machine
Carries animal passengers (cats, dogs; developers can add more).  
Levels unlock new vehicle tiers; each tier contains six selectable variants.

### Delivery Machine
Moves packages and supplies.  
Levels unlock vans → trucks → cargo trucks, each with six variants.

### Shopping Machine
Processes grocery/supply orders.  
Levels unlock baskets → carts → mega carts, each with six variants.

## 4. Continuity Meters
- Food  
- Pet Food  
- Fuel  
- Maintenance  
Meters decay over time; receipts refill them.

## 5. Receipts
Receipts come from in‑game purchases and ERA imports.  
Receipts refill continuity meters and track symbolic stability.

## 6. Home Progression
Shack → Cottage → House → Keep → Fortress → Palace  
Each tier contains six selectable variants.

## 7. Customization Layer
Players choose:
- vehicles  
- homes  
- pets  
- backdrops  
- weather  
- collectibles  

## 8. Developer Expansion
Developers can add:
- vehicle packs  
- home packs  
- pet packs  
- backdrop packs  
- weather packs  
- collectible packs
