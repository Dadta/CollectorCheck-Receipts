# PhoneBurp

PhoneBurp is a symbolic gig‑economy continuity simulator with deep player customization and developer‑expandable content packs.

## Features
- Gig Machines (transport, delivery, shopping)
- Continuity meters (food, pet food, fuel, maintenance)
- Receipts (in‑game + ERA)
- Home progression (six tiers, six variants each)
- Vehicle progression (six variants per tier)
- Pet selection (cats, dogs; developers add more)
- Backdrops and weather themes
- Collectibles
