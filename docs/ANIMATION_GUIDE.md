# Animation Guide

## Style
Short, expressive, readable, loopable.

## Vehicles
Idle: bounce, wheel wiggle  
Movement: wheel turn, forward lean

## Pets
Idle: tail wag, ear twitch  
Hunger: bowl stare  
Passenger: hop in/out

## Homes
Optional chimney smoke, light flicker.

## Backdrops
Optional squirrels, raccoons, drones.

## Weather
Rain, snow, fog, wind.
