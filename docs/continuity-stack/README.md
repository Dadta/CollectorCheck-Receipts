# Continuity Stack
A unified pipeline for personal, household, and artifact continuity.

The Continuity Stack transforms everyday artifacts — receipts, bills, objects, repairs, provenance — into continuity, identity, and future valuation.

This repository contains the specifications, protocols, reference implementations, and developer kits for building continuity-aware applications.

## Architecture
The Continuity Stack is composed of seven layers:

1. Ritual Continuity — PhoneBurp Base
2. Intelligence Continuity — PhoneBurp Thinker
3. Identity Continuity — BurpFrenzy / CastleFrenzy
4. Household Continuity — HydroFrenzy
5. Archivist Continuity — Archive Savior
6. Artifact Continuity — CollectorCheck
7. Global Continuity — Ditto + Dadtabus

Each layer has:
- a protocol
- a data model
- a continuity score contribution
- a developer API
- a reference implementation

## Core Concepts
Continuity, Castle, BurpPoints, PuffTokens, Binder, Continuity Score.
