# Continuity Stack Architecture

The Continuity Stack is a multi-layer continuity engine.

Layers:
1. Ritual — PhoneBurp Base
2. Intelligence — PhoneBurp Thinker
3. Identity — BurpFrenzy / CastleFrenzy
4. Household — HydroFrenzy
5. Archivist — Archive Savior
6. Artifact — CollectorCheck
7. Global — Ditto + Dadtabus

Each layer defines:
- Data model
- Protocol
- API surface
- Continuity score contribution
- Integration points
