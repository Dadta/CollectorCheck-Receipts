# Contributing to the Continuity Stack

We welcome contributions from developers, designers, archivists, insurers, gig workers, and continuity stewards.

## How to Contribute
- Fork the repo
- Create a feature branch
- Submit a pull request
- Follow the module guidelines

## Good First Issues
- continuity-engine
- provenance
- castle-ui
- binder-export
- artifact-ingestion

## Code of Conduct
Be respectful, constructive, and continuity-focused.
