# continuity-engine
A unified continuity engine with a multi‑module dashboard for receipts, artifacts, household stability, identity progression, PuffTokens, castle rooms, and continuity routing.

The Continuity Engine is a unified system that tracks and visualizes personal continuity across multiple domains: receipts, artifacts, household stability, identity progression, PuffToken rewards, castle rooms, and continuity routing.

It includes:

- A multi-module backend (Node.js + Express)
- A unified dashboard with charts, live updates, notifications, sound cues, animations, narrative mode, cinematic mode, and an AI assistant
- Individual module clients (PhoneBurp, CastleFrenzy, HydroFrenzy, Archive Savior, CollectorCheck, Ditto, Dadtabus)
- A continuity score and binder export
- A real-time continuity event system
