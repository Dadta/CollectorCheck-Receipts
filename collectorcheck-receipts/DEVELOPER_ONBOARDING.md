# Developer Onboarding

Welcome to CollectorCheck. This guide helps new contributors understand the project structure and begin contributing quickly.

## Project Structure

- **backend/** — Express server, API routes, SQLite integration  
- **frontend/** — Minimal HTML/JS interface  
- **db/** — SQLite database and schema  
- **public/** — Static assets  
- **README.md** — Contributor guide  
- **package.json** — Scripts and dependencies  

## Running the Project

1. Install dependencies  
   `npm install`

2. Start the server  
   `npm start`

3. Open the app  
   http://localhost:3001

## Good First Tasks

- Improve receipt upload UI  
- Add OCR support  
- Add biller sync  
- Add export options  
- Improve schema  
- Add basic tests  

## Contribution Philosophy

CollectorCheck is built from small, trustworthy modules.  
Each module solves one problem well.  
Minimalism is a contributor magnet.
