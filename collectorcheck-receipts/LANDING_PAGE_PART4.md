# Landing Page Part 4 — The Contributor Invitation

CollectorCheck is intentionally small. It is built from modules that are easy to understand, easy to trust, and easy to extend.

If you build tools, if you like minimal systems, or if you want to help shape the continuity layer for gig workers and small businesses, you are welcome here.

## What you can help build
- better receipt capture
- biller integrations
- artifact verification
- identity continuity
- export tools
- small UI improvements
- documentation
- tests
- new modules

## Why your contribution matters
CollectorCheck is not a startup. It is infrastructure for real people who generate hundreds of receipts per year across everyday apps — McDonald’s, Tim Hortons, Walmart, Amazon, gas stations, grocery stores, pharmacies, and drive‑throughs.

Small contributions make a large difference.

## How to join
Visit the GitHub repo.  
Read the Contributor Guide.  
Pick a small issue.  
Open a PR.

CollectorCheck is built for builders.
