# FAQ Part 2 — Realistic User Cases

This FAQ covers practical, real‑world situations where CollectorCheck is useful.

## I drive for Uber and DoorDash. Can CollectorCheck help?

Yes. CollectorCheck can store:
- fuel receipts  
- maintenance receipts  
- parking receipts  
- food or supply purchases  
- phone plan expenses  

You can generate a clean gig‑work summary at tax time.

## I travel for work. Can I use this for reimbursements?

Yes. CollectorCheck keeps:
- hotel receipts  
- meals  
- transportation  
- conference fees  

You can export a CSV or summary bundle for your employer.

## I run a small business. Is this enough?

If you only need receipt storage and clean records, yes.  
CollectorCheck is not an accounting platform — it’s a receipts engine.

## Can I use it for personal budgeting?

Absolutely. Many users track:
- groceries  
- household purchases  
- recurring expenses  
- one‑off large purchases  

The summaries make budgeting easier.

## Does it work offline?

Yes. CollectorCheck uses SQLite and runs locally.  
No cloud dependency, no account required.
