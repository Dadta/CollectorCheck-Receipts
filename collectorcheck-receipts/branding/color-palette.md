# CollectorCheck U.S.A — Brand Color Palette

## Primary Colors
- **Primary Blue** — #1A73E8  
  Clean, modern, trustworthy. Used for accents, highlights, and UI elements.

- **Deep Navy** — #0B1C2C  
  Professional, stable, ideal for backgrounds and hero sections.

## Accent Colors
- **Mint Accent** — #4BE1C3  
  Fresh, energetic highlight color for icons, buttons, and callouts.

- **Soft Gray** — #F5F7FA  
  Neutral background for cards, panels, and light UI components.

## Utility Colors
- **White** — #FFFFFF  
  Text, icons, and high-contrast elements.

## Usage Guidelines
- Use Deep Navy for large backgrounds.
- Use Primary Blue for interactive elements.
- Use Mint Accent sparingly for emphasis.
- Use Soft Gray for subtle separation.
- Maintain high contrast for accessibility.
