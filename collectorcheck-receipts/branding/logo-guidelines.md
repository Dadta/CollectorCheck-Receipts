# CollectorCheck U.S.A — Logo Guidelines

## Logo Style
- Minimal, geometric, modern.
- Outline-style iconography.
- Rounded corners (4–6px radius).
- Clean typography using Inter.

## Logo Elements
- Receipt outline (primary symbol)
- Cloud or sync arrows (secondary symbol)
- Optional Windows laptop silhouette for platform identity

## Color Usage
- Primary Blue (#1A73E8) for main icon
- Mint Accent (#4BE1C3) for highlights
- White (#FFFFFF) for dark backgrounds
- Deep Navy (#0B1C2C) for light backgrounds

## Clear Space
- Maintain padding equal to the height of the receipt icon.

## Minimum Size
- 32px height for UI
- 128px height for hero sections

## Incorrect Usage
- Do not stretch or distort.
- Do not apply heavy shadows.
- Do not change corner radius.
- Do not use unapproved colors.
