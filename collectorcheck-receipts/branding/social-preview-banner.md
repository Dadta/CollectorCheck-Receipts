# CollectorCheck U.S.A — Social Preview Banner Specification

- Full-width horizontal banner (1200 × 630 recommended for GitHub social preview)
- Left side: bold headline + subheadline
- Right side: minimal icon cluster (receipt, scanner, cloud, Windows laptop)
- Background: diagonal gradient with modern contrast

- Primary Blue: #1A73E8

- Headline: Inter ExtraBold, 48–56px, white
- Subheadline: Inter Medium, 24–28px, mint (#4BE1C3)

"Collect. Automate. Sync."

- Gradient: Deep Navy → Primary Blue with mint glow behind icons
