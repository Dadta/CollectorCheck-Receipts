# Minimal Website Structure

```
/
├── index.html              # Landing Page (Parts 1–4)
├── css/
│   └── style.css           # Minimal styling
├── js/
│   └── main.js             # Optional interactivity
├── assets/
│   └── logo.svg            # Simple CollectorCheck logo
├── pages/
│   ├── receipts.html       # MVP module page
│   ├── continuity.html     # Continuity Engine explanation
│   ├── contributors.html   # Contributor Guide summary
│   └── roadmap.html        # Optional roadmap
└── docs/
    ├── LPP1.md
    ├── LPP2.md
    ├── LPP3.md
    └── LPP4.md
```

Notes:
- index.html contains the four landing page parts.
- pages/ contains module pages and contributor info.
- docs/ stores the markdown versions of the landing page parts.
- No frameworks. No complexity.
