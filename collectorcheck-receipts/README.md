
# CollectorCheck U.S.A

CollectorCheck U.S.A is a clean, modern receipt collector built for freelancers, gig workers, and small businesses.

- **Mobile** — scan and upload receipts  
- **Windows** — automate ingestion and parse PDFs  
- **Cloud** — store and sync your receipt vault

CollectorCheck is intentionally simple. It is not an accounting app or tax tool. It is a universal receipt collector with a developer-friendly architecture.

## Windows Automation (Developer Focus)
Windows is the full-power mode of CollectorCheck:
- Folder watcher for Downloads
- PDF ingestion and parsing
- OCR pipeline
- Business/Personal tagging
- CSV/Excel export
